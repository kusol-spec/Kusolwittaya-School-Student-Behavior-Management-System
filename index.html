เมนูด่วนระบบ

เข้าถึงฟังก์ชันบันทึกข้อมูลพฤติกรรมและการประเมินได้อย่างรวดเร็ว

ระบบข้อมูลส่วนตัว (นักเรียนเข้าชมเฉพาะตนเอง แอดมินดูได้ทั้งหมด)

ทำเนียบนักเรียนและฐานข้อมูลพฤติกรรม 4 ด้าน

จัดการข้อมูลนักเรียน ตรวจสอบพฤติกรรมรายบุคคล และคะแนนความประพฤติ

รูป / นักเรียน เลขประจำตัว / ชั้น คะแนนความประพฤติ 1. การเรียน 2. สังคม/วินัย 3. อารมณ์/จิตใจ 4. ความปลอดภัย/เสี่ยง จัดการ

ลงเวลาเข้าเรียนรายวัน

ครู/แอดมินสามารถลงเวลาที่นักเรียนมาถึงจริงได้ทุกช่วงเวลา เนื่องจากนักเรียนแต่ละคนมาไม่พร้อมกัน ระบบจะเทียบกับเวลามาตรฐานของนักเรียนแต่ละคนเพื่อแจ้งเตือนการมาสายอัตโนมัติ

วันที่ นักเรียน เวลาที่มาถึงจริง เวลามาตรฐาน สถานะ หมายเหตุ / ผู้บันทึก จัดการ

ลงเวลาเข้างานครู/แอดมิน

บันทึกเวลาเข้างานของครูและแอดมินประจำวัน สำหรับใช้ตรวจสอบและติดตามการเข้างานภายในโรงเรียน

วันที่ ชื่อ - นามสกุล ตำแหน่ง เวลาเข้างาน สถานะ หมายเหตุ จัดการ

เครื่องมือและแบบประเมินมาตรฐาน

บันทึกและจัดการผลประเมิน SDQ, EQ, การเยี่ยมบ้าน และสมุดสังเกตพฤติกรรม

แบบประเมินความฉลาดทางอารมณ์ (EQ) 52 ข้อ

ประเมินตนเองใน 3 ด้าน ได้แก่ ดี · เก่ง · สุข ใช้เวลาประมาณ 10–15 นาที ไม่มีถูกผิด ตอบตามความรู้สึกจริงของตัวเอง

วันที่ประเมิน ชื่อนักเรียน ประเภทแบบประเมิน ผลการประเมิน / สรุป ผู้ประเมิน จัดการ

เชื่อมต่อกับ Google Sheets

ทุกครั้งที่มีการบันทึก/แก้ไข/ลบข้อมูล ระบบจะส่งข้อมูลล่าสุดทั้งหมดขึ้นไปบันทึกใน Google Sheet ของคุณโดยอัตโนมัติ

วิธีตั้งค่า (ทำครั้งเดียว):

  1. เปิด Google Sheet ที่ต้องการใช้เก็บข้อมูล
  2. ไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
  3. วางโค้ด Google Apps Script (ดาวน์โหลดไฟล์ Code.gs ที่ให้มาพร้อมระบบ) แล้วบันทึก
  4. กด Deploy → New deployment → เลือกประเภท "Web app"
  5. ตั้งค่า "Who has access" เป็น "Anyone" แล้วกด Deploy พร้อมอนุญาตสิทธิ์ (Authorize)
  6. คัดลอกลิงก์ Web App URL ที่ได้ (ลงท้ายด้วย /exec) มาวางด้านล่างนี้

ยังไม่ได้เชื่อมต่อ Google Sheets — ข้อมูลจะถูกบันทึกในเครื่อง/ออนไลน์ภายในระบบเท่านั้น
